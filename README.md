# NGS アバンダク計算ツール

『PHANTASY STAR ONLINE 2 New Genesis』(PSO2:NGS) の武器・防具に付与する特殊能力を組み立てながら、**重複を除いた総特殊能力数**をリアルタイムで集計する、ブラウザだけで動くシンプルな計算ツールです。

- 単一の `index.html` のみで動作 (ビルド・サーバー不要)
- すべての処理はブラウザ内で完結し、外部への通信・データ送信なし

## 使い方

1. `index.html` をブラウザで開く (ダブルクリックでOK)
2. 武器1 + 防具3 × 各8スロットのプルダウンで特殊能力を選択
3. 上部サマリーに「重複を除いた総特殊能力数」と「選択済みスロット数」が表示される

## 主な機能

| 機能 | 説明 |
|---|---|
| 総特殊能力数の集計 | 32スロット中の選択を重複自動除外してカウント |
| EXOP1〜3 自動入力 | トグルで武器の1〜3番スロットに一括設定・解除 |
| 全複製 | 選択中の装備の内容を他の装備へ一括コピー |
| クリア | 装備単位での選択解除 |
| カスタム能力管理 | 「能力管理」ボタンから能力を自由に追加・削除 (localStorage に保存) |
| バックアップ | カスタム能力を JSON でエクスポート/インポート (他 PC への移行・共有に) |
| 自動保存 | 選択状態を自動でブラウザに保存 (再読み込みでも復元) |
| テーマ | ダーク / ライト / サイバー / ミント (選択を記憶) |

## 能力データの追加方法

### 1. 画面から追加 (おすすめ)

ツール右上の「能力管理」モーダルから、コードを編集せずに能力を追加・削除できます。
追加した能力はブラウザの localStorage に保存され、デフォルトデータと自動的にマージされます。

### 2. コードで追加

`index.html` 内の `DEFAULT_ABILITY_DATA` を編集します:

```js
// 既存カテゴリに能力を追加する場合
{ category: "ユディ:ダホウ", items: ["ユディ･アムダホウ", "...", "新しい能力名"] }

// カテゴリ自体を追加する場合 (1行まるごと追記)
{ category: "新カテゴリ", items: ["能力A", "能力B"] },
```

> **注意**: 選択状態は「能力名」で保存されるため、既存の名前を変更すると過去に選んでいたスロットが未選択に戻ります。

## GitHub Pages で公開する

1. GitHub で新規リポジトリを作成し、このリポジトリを push
2. リポジトリの **Settings → Pages → Branch** で `main` / `(root)` を選択して Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 免責・注意

- 本ツールは非公式のファンメイドツールであり、SEGA および『PHANTASY STAR ONLINE 2 New Genesis』とは関係ありません
- 特殊能力名は手入力のため、ゲーム内の正式名称と異なる表記が含まれる可能性があります (修正 PR・Issue を歓迎します)
- データはブラウザの localStorage に保存されます。ブラウザのデータ削除で消えるため、必要に応じて JSON バックアップをご利用ください
